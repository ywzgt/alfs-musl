xdg-desktop-portal-wlr-0.8.3

Introduction to xdg-desktop-portal-wlr

The xdg-desktop-portal-wlr package provides the screenshot and screencast portal interfaces for wlroots compositors. Most of the other portal interfaces are provided by xdg-desktop-portal-gtk-1.15.3, but isn't strictly required unless you need those interfaces.

Note

Development versions of BLFS may not build or run some packages properly if LFS or dependencies have been updated since the most recent stable versions of the books.

Installation of xdg-desktop-portal-wlr

Install xdg-desktop-portal-wlr by running the following commands: 

mkdir build &&
cd    build &&

meson setup --prefix=/usr       \
            --buildtype=release \
            .. &&
ninja

This package doesn't come with a test suite.

Now, as the root user: 

ninja install

Ensure the portal can be detected as the root user: 

cat > /usr/share/xdg-desktop-portal/wlr-portals.conf << "EOF"
[preferred]
default=wlr
EOF

Note

If xdg-desktop-portal-wlr is installed and Xfce is run under X11, the xfce-portals.conf file in /usr/share/xdg-desktop-portal tells xdg-desktop-portal to try the wlr backend first for screen casting. The wlr backend's user service is skipped when WAYLAND_DISPLAY is not set, but the portal is not told about it and waits 25 seconds for a D-Bus timeout every time it starts. Applications that query the portal stall for the same amount of time. To avoid this, override the setting for your user: 

mkdir -pv ~/.config/xdg-desktop-portal &&
sed 's/^org.*.ScreenCast=.*/org.freedesktop.impl.portal.ScreenCast=none/' \
    /usr/share/xdg-desktop-portal/xfce-portals.conf \
    > ~/.config/xdg-desktop-portal/xfce-portals.conf

This disables the screen cast portal in all Xfce sessions for that user, including Wayland sessions. Do not make this change if you run Xfce under Wayland.
