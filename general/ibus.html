ibus-1.5.35

Introduction to ibus

ibus is an Intelligent Input Bus. It is a new input framework for the Linux OS. It provides a fully featured and user friendly input method user interface.

Note

Development versions of BLFS may not build or run some packages properly if LFS or dependencies have been updated since the most recent stable versions of the books.

Package Information

  • Download (HTTP): https://github.com/ibus/ibus/archive/1.5.35/ibus-1.5.35.tar.gz

  • Download MD5 sum: 7abdebf2faad614644c38d286b3874e1

  • Download size: 1.9 MB

  • Estimated disk space required: 119 MB (with tests)

  • Estimated build time: 0.5 SBU (Using parallelism=4; add 1.4 SBU for tests)

ibus Dependencies

Required

Recommended

DConf-51.0, GLib-2.90.1 (with GObject Introspection), GTK-3.24.52, GTK-4.24.1, and libnotify-0.8.9

Optional

gnome-desktop-51.0 (for one test), GTK-Doc-1.37.0 (for generating API documentation), libxkbcommon-1.13.2, PyGObject-3.58.1 (for ibus-setup), Wayland-1.26.0 (to build the Wayland support programs), EmojiOne, and libdbusmenu

Installation of ibus

First, install the Unicode Character Database as the root user: 

python3 -m zipfile -e ../UCD.zip /usr/share/unicode/ucd

Fix an issue with deprecated schema entries: 

sed -e 's@/desktop/ibus@/org/freedesktop/ibus@g' \
    -i data/dconf/org.freedesktop.ibus.gschema.xml

Install ibus by running the following commands: 

mkdir build &&
cd    build &&

meson setup ..                    \
            --prefix=/usr         \
            --buildtype=release   \
            -D appindicator=false \
            -D emoji-dict=false   \
            -D gtk-doc=false      \
            -D tests=false        &&
ninja

To test the results, issue: 

meson configure -D tests=true -D distro-tests=true &&
sed 's/python$/&3/' -i ../engine/test-gnome.py     &&
ninja test

The test named ibus-compose fails because it uses some locales not installed in LFS. The test named ibus-keypress requires CONFIG_INPUT_UINPUT enabled in the kernel configuration and it would fail otherwise. The test named test_gnome.py is known to fail with xkeyboard-config 2.49 or newer. The xkb-latin-layouts test is also known to fail on some systems.

Now, as the root user: 

make install

Command Explanations

-D appindicator=false: This switch disables use of libdbusmenu. Omit if you installed the optional dependency.

-D emoji-dict=false: This switch disables the use of emoticon dictionaries. Omit if you installed the optional package.

-D gtk-doc=false: This switch removes the dependency on Gtk-Doc. Remove it if you've installed the dependency and you wish to build and install the API documentation of this package.

-D gtk4=false: This switch disables building the GTK 4 immodule. Use it if you don't want to install GTK 4.

-D wayland=enabled: This switch enables building the Wayland support programs. It's automatically enabled if both libxkbcommon-1.13.2 and Wayland-1.26.0 are installed.

Configuring Ibus

If GTK+-3 is installed and -D gtk3=false is not used, the ibus IM module for GTK+-3 will be installed. As the root user, update a cache file of GTK+-3 so the GTK-based applications can find the newly installed IM module and use ibus as an input method: 

gtk-query-immodules-3.0 --update-cache

The command above updates the cache file for GTK+-3. GTK-4 does not require a cache file for IM modules.
