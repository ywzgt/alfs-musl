leptonica-1.87.0

Introduction to leptonica

The leptonica package provides software that is broadly useful for image processing and image analysis applications.

Note

This package is known to build and work properly using an LFS 13.1 platform.

Package Information

  • Download (HTTP): https://github.com/DanBloomberg/leptonica/releases/download/1.87.0/leptonica-1.87.0.tar.gz

  • Download MD5 sum: d523d2c883b71850a46af2517d8915bf

  • Download size: 14 MB

  • Estimated disk space required: 128 MB

  • Estimated build time: 0.4 SBU (Using parallelism=4)

leptonica Dependencies

Recommended

libjpeg-turbo-3.2.0, libpng-1.6.58, libwebp-1.6.0, tiff-4.7.2, and OpenJPEG-2.5.4

Installation of leptonica

Install leptonica by running the following commands: 

./autogen.sh &&           

./configure --prefix=/usr --disable-static &&
make

The package does not come with a test suite.

Now, as the root user: 

make install

Contents

Installed Programs: convertfilestopdf, convertformat, convertsegfilestops, converttops, imagetops, convertfilestops, convertsegfilestopdf, converttopdf, fileinfo, and xtractprotos
Installed Library: libleptonica.so
Installed Directories: None
